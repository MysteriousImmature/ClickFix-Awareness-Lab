    STARTER QUERY
    // Hunt for interactive-shell launches of MSHTA.
// Review results; this filter alone does not confirm ClickFix.
DeviceProcessEvents
| where Timestamp > ago(7d)
| where FileName =~ "mshta.exe"
| where InitiatingProcessFileName =~ "explorer.exe"
| project Timestamp, DeviceId, DeviceName, AccountName,
          ProcessId, ProcessCommandLine, InitiatingProcessFileName
| order by Timestamp desc
    Hunt logic is shown for review; it is not connected to a tenant. Adapt to your telemetry, retention, and legitimate HTA use.
    01 / VISIBILITY

    Where the browser ends

    Clipboard staging is a browser action. Windows Run is an OS action performed by the user. MSHTA runs in the user's context; it does not inherently grant administrator rights.

    Microsoft threat research ↗
    02 / RESPONSE

    Validate, then contain

    Review the full process tree, command line, source URL, Run history, and related connections. Ask what the user saw and pasted. Preserve evidence and follow your incident response playbook.

    Sysmon event reference ↗
    03 / PREVENTION

    Break the handoff

    Teach users to stop when a verification prompt asks for Run or a terminal. Consider application control for MSHTA where unneeded, validated in audit mode before enforcement.
